# UGC Flow Studio

A visual product-to-video workflow dashboard built with Next.js. Upload a product image, add creative direction, run a six-stage simulated AI production workflow, and review the resulting video in the same interface.

## Local development

```bash
npm install
npm run dev
```

The first version uses a credit-free simulated workflow so the complete interaction can be reviewed before a production video provider, durable storage, and authentication are connected.

## Roadmap

- Connect a production AI video provider
- Add durable workflow and asset storage
- Add authentication and workspace ownership
- Add workflow history, retry, cancellation, and cost controls
